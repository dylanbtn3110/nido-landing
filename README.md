# Nido · Landing Page

Landing page de **Nido**, gestión inteligente de alojamientos temporales (US20).
Proyecto del curso *Arquitectura de Aplicaciones Web* (UPC, 2026-20).

- HTML5, CSS3 y JavaScript sin frameworks, con la guía de estilo de Nido (Poppins, Inter y la paleta 60-30-10).
- Responsive (breakpoints 1200, 1024, 768 y 480 px).
- Publicada con **GitHub Pages**.

## Ejecutar en local
Abre `index.html` en el navegador o sirve la carpeta con cualquier servidor estático.

## Configuración
En `js/config.js` se define la URL de la aplicación web (botón "Iniciar sesión") y el correo de contacto.
Cuando el backend esté desplegado en AWS, reemplaza `NIDO_APP_URL` por la URL pública.
